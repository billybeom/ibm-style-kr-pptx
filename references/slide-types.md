# IBM 슬라이드 유형

모든 IBM 프레젠테이션은 아래 필수 구조를 따릅니다:

```
[커버 슬라이드] → [셀러 가이던스/법적 고지 (선택)] → [목차 (선택)] → [섹션 구분자 + 콘텐츠 슬라이드] → [엔딩 슬라이드]
```

- **슬라이드 1은 항상 커버** — 예외 없음, 페이지 번호 없음
- **슬라이드 2 (선택)**: 셀러 가이던스 & 법적 고지 — 셀러/제품 덱에서 사용
- **마지막 슬라이드는 항상 엔딩** — 예외 없음, 페이지 번호 없음
- **그 외 모든 슬라이드에는 페이지 번호 포함** (x=25.75" y=14.16")
- **모든 콘텐츠 슬라이드**는 아래 IBM 템플릿 카테고리 중 정확히 하나로 분류
- **webMethods / Hybrid Integration** 셀러 발표 자료는 [webmethods-template.md](webmethods-template.md) 참고

## 필수: 커버 슬라이드

**첫 번째 슬라이드. 페이지 번호 없음.**

**목적**: 브랜드 정체성, 발표 제목, 톤 확립.

**IBM 커버 레이아웃 좌표 (가장 일반적 — 반쪽 이미지 변형)**:

| 요소 | x | y | w | h |
|------|---|---|---|---|
| 제목 | 0.63" | 0.34" | 11.05" | 11.33" |
| 이미지 (우측 반쪽) | 13.96" | 0.63" | 12.08" | 13.76" |

**커버 변형 옵션** (콘텐츠에 맞게 하나 선택):

| 변형 | 설명 | 사용 시점 |
|------|------|-----------|
| `Cover, imagery, half` | 좌측 제목 + 우측 반쪽 전체 이미지 | 기본 커버 — 가장 전문적 |
| `Cover, imagery, half, label` | 상단 레이블 밴드 + 제목 + 반쪽 이미지 | 섹션/유형 레이블이 필요할 때 |
| `Cover, plain, label` | 흰색 커버 — 상단 레이블, 대형 제목, 이미지 없음 | 사진이 없을 때 |
| `Cover, cyan` | 연한 파란색 `#BAE6FF` 배경 | 대체 브랜딩, 내부 발표 자료 |

**커버 디자인 규칙**:
- 제목은 **44–88pt**, `IBM Plex Sans KR Light` 또는 `IBM Plex Sans KR ExtLt`
- 이미지는 **우측 반쪽** 차지 (x > 13.96")
- 좌측 반쪽은 어두운 텍스트의 흰색 배경
- 선택적 아이브로/레이블 텍스트 (상단): 28pt, `IBM Plex Sans KR Medm`
- 선택적 IBM 블루 강조 점 (`#0F62FE`, ~0.42" 원) — x=25.62", y=0.63"
- **커버 슬라이드에 페이지 번호 없음**

```javascript
// IBM 커버 — 반쪽 이미지 변형
function createSlide(pres, theme) {
  const slide = pres.addSlide();
  slide.background = { color: theme.bg };

  // 선택: 아이브로 레이블
  slide.addText("IBM 클라이언트 발표 자료", {
    x: 0.63, y: 0.42, w: 11.05, h: 0.63,
    fontSize: 28, fontFace: "IBM Plex Sans KR Medm",
    color: theme.primary, bold: false, align: "left"
  });

  // 메인 제목
  slide.addText("발표 제목", {
    x: 0.63, y: 1.25, w: 11.05, h: 10,
    fontSize: 64, fontFace: "IBM Plex Sans KR Light",
    color: theme.primary, bold: false, align: "left"
  });

  // 우측 반쪽 이미지 플레이스홀더 (실제 이미지 경로로 교체)
  // slide.addImage({ path: "imgs/cover.jpg", x: 13.96, y: 0.63, w: 12.08, h: 13.76 });

  // 커버에 페이지 번호 없음
  return slide;
}
```

## 필수: 엔딩 슬라이드

**마지막 슬라이드. 페이지 번호 없음.**

**목적**: 최종 IBM 브랜드 마무리 — 감사 인사, 연락처, IBM 브랜드 클로징.

**디자인 규칙**:
- 보통 전체 화면 IBM 브랜드 이미지 또는 IBM 블루 배경
- 최소 텍스트 (감사 메시지, 연락처 정보, IBM 로고)
- **페이지 번호 없음**

```javascript
// IBM 엔딩 슬라이드
function createSlide(pres, theme) {
  const slide = pres.addSlide();
  slide.background = { color: "003A6D" };  // IBM 진한 남색 엔딩용

  slide.addText("감사합니다", {
    x: 0.63, y: 4.5, w: 20, h: 4,
    fontSize: 88, fontFace: "IBM Plex Sans KR Light",
    color: "FFFFFF", bold: false, align: "left"
  });

  slide.addText("www.ibm.com", {
    x: 0.63, y: 12, w: 10, h: 0.8,
    fontSize: 28, fontFace: "IBM Plex Sans KR Light",
    color: "BAE6FF", bold: false, align: "left"
  });

  // 엔딩 슬라이드에 페이지 번호 없음
  return slide;
}
```

섹션이 3개 이상일 때 사용. 커버 슬라이드 바로 다음에 배치.

|------|---|---|---|---|
| 제목 | 0.63" | 0.63" | 5.41" | 1.67" |
| 섹션 목록 | 0.63" | 3.33" | 25.42" | 10.01" |
| 푸터 | 0.63" | 14.02" | 5.42" | 0.42" |
| 페이지 번호 | 25.75" | 14.16" | 0.30" | 0.27" |

**디자인 규칙**:
- 페이지 제목 "목차" 또는 "Agenda"를 44pt, `IBM Plex Sans KR Light`로 표기
- 섹션 번호는 IBM 블루 (`#0F62FE`) 또는 볼드, 36–44pt
- 섹션 제목은 28–36pt, `IBM Plex Sans KR`
- **페이지 번호 필수**

## 콘텐츠 슬라이드 카테고리

각 콘텐츠 슬라이드에 가장 적합한 템플릿 카테고리를 선택하십시오. **시각적 다양성**을 확보하기 위해 연속된 슬라이드에 같은 카테고리를 반복하지 마십시오.

**사용 시점**: 슬라이드 전체를 지배하는 굵은 수치, 도발적인 질문, 또는 강력한 주장 하나.

| 페이지 번호 | 25.75" | 14.16" | 0.30" | 0.27" |

- 헤드라인은 **84pt** `IBM Plex Sans KR` — 슬라이드를 지배
- 수치는 84–168pt 볼드, 설명 캡션은 28pt

- 헤더 행: `IBM Plex Sans KR SmBld` 또는 `IBM Plex Sans KR Medm`, **20pt**, IBM 블루(`#0F62FE`) 배경에 흰색 텍스트
- 본문 행: `IBM Plex Sans KR` **20pt**, `#414141` 텍스트, 흰색/`#F4F4F4` 교차 배경
- 테두리: 얇은 `#E0E0E0` 수평선만 (본문 행 세로 테두리 금지)
- 첫 번째 컬럼은 행 헤더로 볼드 가능
- **예외**: 표 본문 텍스트 20pt는 허용 (28pt 최소 규칙의 유일한 예외)

## 섹션 구분자 (Section Divider)

주요 발표 섹션 사이에 전환을 위해 **섹션 구분자** 슬라이드를 사용합니다.

**IBM 섹션 구분자 좌표**:

| 요소 | x | y | w | h |
|------|---|---|---|---|
| 레이블/아이브로 | 0.63" | 0.42" | 11.04" | 0.63" |
| 섹션 제목 | 0.63" | 1.26" | 11.04" | 10" |
| 푸터 | 0.63" | 14.02" | 5.42" | 0.42" |
| 페이지 번호 | 25.75" | 14.16" | 0.30" | 0.27" |

**디자인 규칙**:
- 섹션 번호는 **44–64pt** `IBM Plex Sans KR SmBld`, IBM 블루
- 섹션 제목은 **44pt** `IBM Plex Sans KR Light`
- 선택적 소개 텍스트는 **28pt** `IBM Plex Sans KR`
- IBM 진한 남색 (`#003A6D`)을 좌측 강조 블록으로 사용 가능
- 콘텐츠 슬라이드와 시각적으로 구분 (더 많은 여백, 더 적은 요소)
- **페이지 번호 필수**

```javascript
// IBM 섹션 구분자
function createSlide(pres, theme) {
  const slide = pres.addSlide();
  slide.background = { color: theme.bg };

  // 좌측 강조 바
  slide.addShape(pres.shapes.RECTANGLE, {
    x: 0.63, y: 0.63, w: 0.12, h: 12.71,
    fill: { color: theme.accent }
  });

  // 섹션 번호
  slide.addText("01", {
    x: 1.05, y: 0.63, w: 11, h: 2,
    fontSize: 64, fontFace: "IBM Plex Sans KR SmBld",
    color: theme.accent, bold: false, align: "left"
  });

  // 섹션 제목
  slide.addText("섹션 제목", {
    x: 1.05, y: 3.33, w: 18, h: 6,
    fontSize: 44, fontFace: "IBM Plex Sans KR Light",
    color: theme.primary, bold: false, align: "left"
  });

  // 페이지 번호 (섹션 구분자에도 필수)
  slide.addText("2", {
    x: 25.75, y: 14.16, w: 0.30, h: 0.27,
    fontSize: 12, fontFace: "IBM Plex Sans KR Light",
    color: theme.primary, align: "center", valign: "middle"
  });

  return slide;
}
```

## IBM 페이지 번호 (커버·엔딩 외 모든 슬라이드 필수)

커버와 엔딩을 제외한 모든 슬라이드에 추가합니다.

```javascript
// IBM 페이지 번호 — 우측 하단 고정 위치
slide.addText(String(slideIndex), {
  x: 25.75, y: 14.16, w: 0.30, h: 0.27,
  fontSize: 12, fontFace: "IBM Plex Sans KR Light",
  color: "000000", align: "center", valign: "middle"
});
```

IBM 블루 점 변형도 사용 가능:

```javascript
// IBM 블루 점 페이지 번호
slide.addShape(pres.shapes.OVAL, {
  x: 25.7, y: 14.1, w: 0.4, h: 0.4,
  fill: { color: "0F62FE" }
});
slide.addText(String(slideIndex), {
  x: 25.7, y: 14.1, w: 0.4, h: 0.4,
  fontSize: 12, fontFace: "IBM Plex Sans KR Light",
  color: "FFFFFF", bold: false,
  align: "center", valign: "middle"
});
```

## 템플릿 선택 가이드

덱을 기획할 때 각 콘텐츠 슬라이드에 적합한 템플릿을 선택하는 결정 트리:

| 콘텐츠 유형 | 권장 카테고리 |
|------------|--------------|
| 강력한 수치 하나 또는 굵은 주장 | Big Trending |
| 단일 내러티브, 케이스 스터디 | 1단 |
| 도전 + 해결책, A vs B 비교 | 2단 |
| 3가지 프레임워크, 3가지 역할 | 3단 |
| 4가지 기둥, 4개 경쟁사 | 4단 |
| 2가지 주요 주제 쌓기 | 2행 |
| 3단계 순서 / 순위 항목 | 3행 |
| 4분면 성과 | 2행×2열 |
| 6가지 제품 기능 / 파트너 | 2행×3열 |
| 6–8항목 엔터프라이즈 모델 | 2행×4열 |
| 9셀 전략 매트릭스 | 3행×3열 |
| 납품 타임라인 / 간트 | 프로젝트 플랜 |
| 지표 표, 기능 비교 | 표 |
| 섹션 전환 | 섹션 구분자 |

**다양성 규칙**: 연속되는 콘텐츠 슬라이드에 같은 카테고리를 사용하지 마십시오. 컬럼 중심 레이아웃, 행 기반 레이아웃, 콜아웃/빅트렌딩 슬라이드를 교차 배치하여 시각적 흥미를 유지하십시오.
