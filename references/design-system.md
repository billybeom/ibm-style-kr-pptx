## IBM 색상 팔레트

### 주요 테마 색상 (모든 IBM 덱에 필수 적용)

| 토큰 | Hex | 역할 |
|------|-----|------|
| IBM 블루 (accent1) | `#0F62FE` | **주요 강조색** — 페이지 번호 점, 하이라이트, 링크, 활성 표시자 |
| 검정 (lt1) | `#000000` | 모든 본문 텍스트, 흰 배경 위 제목 |
| 흰색 (dk1) | `#FFFFFF` | 슬라이드 배경, 어두운 배경 위 텍스트 |
| 진한 회색 | `#414141` | 표 본문 텍스트, 보조 정보, 흐린 레이블 |
| 연한 파란색 | `#BAE6FF` | 커버 레이블 밴드 채우기, 배경 보조색 |
| 진한 남색 (accent3) | `#003A6D` | 강한 강조, 섹션 구분자 배경 |
| 보라색 (accent2) | `#A56EFF` | 장식용 강조색 (최소 사용) |
| 청록색 (accent4) | `#009D9A` | 데이터 시각화 강조색 |
| 마젠타 (accent5) | `#9F1853` | 경고 또는 콜아웃 강조색 (최소 사용) |
| 빨간색 (accent6) | `#FA4D56` | **경고/오류 전용** — 일반 콘텐츠에 절대 사용 금지 |
| 초록색 | `#229338` | 긍정적 수치, 성장 지표 |

### 배경 색상

- **기본 슬라이드 배경**: 흰색 (`#FFFFFF`) — 모든 표준 콘텐츠 슬라이드에 사용
- **커버 레이블 밴드** (슬라이드 11 변형): `#BAE6FF` — 연한 파란색 전체 화면
- **표준 콘텐츠 슬라이드에 어두운 전체 배경 금지** (어두운 효과는 전체 화면 이미지로만 구현)

### IBM 테마 오브젝트 (PptxGenJS — 아래 키를 반드시 사용)

```javascript
const theme = {
  primary:   "000000",   // 검정 — 본문 텍스트, 흰 배경 위 제목
  secondary: "414141",   // 진한 회색 — 보조 텍스트, 표 본문
  accent:    "0F62FE",   // IBM 블루 — 강조색, 페이지 번호, 하이라이트
  light:     "BAE6FF",   // 연한 파란색 — 레이블 밴드, 은은한 채우기
  bg:        "FFFFFF"    // 흰색 — 기본 슬라이드 배경
};
```

**다른 키 이름 절대 사용 금지** (`background`, `text`, `muted`, `darkest`, `lightest` 등).

## IBM 타이포그래피

### 폰트 패밀리

모든 IBM 프레젠테이션은 **IBM Plex Sans KR**을 단독으로 사용합니다. Arial, Helvetica, Calibri 또는 다른 폰트 패밀리와 절대 혼용하지 마십시오.

| 폰트 굵기 | PptxGenJS fontFace | 굵기 | 주요 사용처 |
|-----------|-------------------|------|-------------|
| 엑스트라 라이트 | `IBM Plex Sans KR ExtLt` | 200 | 커버 슬라이드 대형 표시 제목 |
| 라이트 | `IBM Plex Sans KR Light` | 300 | 기본 본문 텍스트, 부제목, 캡션, 페이지 번호 |
| 레귤러 | `IBM Plex Sans KR` | 400 | 일반 본문 텍스트, 컬럼, 불릿 텍스트 |
| 미디엄 | `IBM Plex Sans KR Medm` | 500 | 강조 본문, 레이블, 부제목 |
| 세미볼드 | `IBM Plex Sans KR SmBld` | 600 | 섹션 번호, 강한 콜아웃, 표 헤더 |

> 한국어 및 CJK 콘텐츠는 **IBM Plex Sans KR** 패밀리가 기본 지원합니다 — 별도 CJK 폰트 불필요.
> 슬라이드 마스터의 테마 주요/보조 폰트는 `IBM Plex Sans KR Light`로 해석됩니다 (`+mj-lt` / `+mn-lt`).

### 폰트 크기 체계

| 크기 | 사용처 |
|------|--------|
| **168pt** | 커버 초대형 표시 (극강 강조) |
| **130pt** | 데이터 콜아웃 초대형 숫자 |
| **88–86pt** | 커버 슬라이드 메인 제목 (대형 표시) |
| **84pt** | Big Trending 헤드라인 |
| **72pt** | 커버 표시 변형 |
| **64pt** | 대형 섹션 제목 / 1단 콘텐츠 제목 |
| **44pt** | 섹션 구분자 제목, 주요 슬라이드 제목 |
| **36pt** | 컬럼 제목, 표 제목 |
| **28pt** | 레이블 라인, 부제목, 아이브로 텍스트 — **IBM Plex Sans KR 본문 최소 크기** |
| **24pt** | 컬럼 소제목, 중간 본문 |
| **20pt** | 표 본문, 프로젝트 플랜 텍스트 (28pt 최소 규칙의 유일한 예외) |
| **16pt** | 각주 (사용 최소화) |

### 타이포그래피 규칙

- **IBM Plex Sans KR 본문/레이블 텍스트 최소 28pt** — 표(20pt 허용)를 제외하고 이보다 작게 사용 금지
- **제목**은 `IBM Plex Sans KR Light` 또는 `IBM Plex Sans KR ExtLt` 사용 — 대형 크기에서 가벼운 굵기가 더 보기 좋음
- **본문 텍스트**는 `IBM Plex Sans KR` 레귤러 또는 라이트 사용
- **데이터 콜아웃** (큰 숫자)은 `IBM Plex Sans KR Medm` 또는 `IBM Plex Sans KR SmBld` 사용
- **레이블 / 섹션 태그**는 `IBM Plex Sans KR Medm` 28pt 사용
- **이탤릭체 금지** — IBM Plex는 프레젠테이션에서 로만체만 사용
- **볼드는 최소한으로** — 데이터 숫자와 헤더에만 사용, 일반 본문 금지
- **본문 텍스트는 좌측 정렬** — 단락이나 불릿 목록을 가운데 정렬하지 않음

## IBM 레이아웃 그리드

### 4단 그리드

IBM 슬라이드는 기본 단위로 **4단 그리드**를 사용합니다:

| 영역 | x 시작 | 너비 | 비고 |
|------|--------|------|------|
| 컬럼 1 | 0.63" | 5.41" | 제목 / 좌측 레일 |
| 컬럼 2 | 7.29" | 5.41" | 콘텐츠 컬럼 2 |
| 컬럼 3 | 13.96" | 5.41" | 콘텐츠 컬럼 3 |
| 컬럼 4 | 20.63" | 5.41" | 콘텐츠 컬럼 4 |
| 거터 | ~1.26" | — | 컬럼 사이 간격 |

> **2단 레이아웃**: 컬럼 1+2 (좌측, 11.04" 너비)와 컬럼 3+4 (우측, 11.04" 너비)로 스팬.

### 수직 영역

| 영역 | y 범위 | 콘텐츠 |
|------|--------|--------|
| 아이브로 / 섹션 태그 | 0.42"–0.63" | 날짜, 레이블, IBM Sales 태그 |
| 제목 영역 | 0.63"–3.33" | 슬라이드 제목 |
| 콘텐츠 영역 | 3.33"–13.34" | 본문 컬럼, 데이터, 이미지 |
| 푸터 | 14.02"–14.44" | 선택적 푸터 텍스트 |
| 슬라이드 번호 | 14.16" | 우측 하단 |

### 안전 영역

- **좌측 여백**: 슬라이드 좌측 가장자리에서 0.63" — 모든 콘텐츠는 이곳부터 시작
- **하단 안전 영역**: y=13.5" 아래에 콘텐츠 배치 금지 (푸터 + 페이지 번호 영역)
- **상단 여백**: 상단에서 0.42"–0.63"

## IBM 디자인 규칙

### ✅ 해야 할 것

- 덱 전체에서 `IBM Plex Sans KR` 패밀리만 사용
- 콘텐츠 슬라이드의 제목 텍스트는 **44pt 이상** 유지
- 인터랙티브/하이라이트 요소에는 IBM 블루 `#0F62FE`만 강조색으로 사용
- 모든 본문 텍스트 좌측 정렬
- 불릿 들여쓰기는 **최대 3단계**로 유지
- 4단 그리드 사용 — 모든 콘텐츠 영역은 그리드 컬럼에 맞춤
- 커버·엔딩 슬라이드 외 모든 슬라이드에 페이지 번호 포함 (x=25.75" y=14.16")
- 배경은 흰색 (`#FFFFFF`) 기본 사용
- 데이터 콜아웃 숫자에는 `IBM Plex Sans KR Medm` 또는 `IBM Plex Sans KR SmBld` 사용
- 모든 콘텐츠 요소의 좌측 여백을 **0.63"**으로 일관되게 유지
- 본문/레이블 텍스트는 **최소 28pt** 유지

### ❌ 하지 말아야 할 것

- 이탤릭체 사용 금지 — IBM Plex는 프레젠테이션에서 로만체만 사용
- 그림자 효과, 3D 효과, 장식용 워드아트 사용 금지
- y=13.5" 아래에 콘텐츠 배치 금지 (푸터 영역)
- 슬라이드당 강조색 2가지 초과 사용 금지
- 제목 가운데 정렬 금지 (IBM은 좌측 정렬 제목 사용)
- 빨간색 (`#FA4D56`)을 일반 콘텐츠에 사용 금지 — 경고/오류에만 사용
- IBM Plex와 다른 폰트 패밀리 혼용 금지
- 대비가 낮은 이미지 위에 텍스트 배치 금지
- 강조에 밑줄 사용 금지 (대신 굵기 변경 사용)
- 텍스트에 드롭 섀도우 추가 금지
- IBM 이외 색상 팔레트 사용 금지 (커스텀 그라디언트, 일반 기업 팔레트 금지)
- 그라디언트 사용 금지 — IBM 프레젠테이션은 단색만 사용
- 슬라이드 전환 또는 애니메이션 사용 금지 — 모든 슬라이드는 정적이어야 함

### 간격 원칙

- 제목 상단 여백: 슬라이드 상단에서 **0.42"–0.63"**
- 콘텐츠 시작 y: **3.33"** (제목 영역 이후)
- 컬럼 거터: **~1.26"** (7.29 - 0.63 - 5.41)
- 본문 텍스트 행간: 폰트 크기의 약 130%
- 단락 앞 간격: 6–12pt

## 이미지 및 미디어

### 배치 규칙

- **반쪽 슬라이드 이미지** (커버, 1단): x=13.96", y=0.63", w=12.08", h=13.76"
- **인셋 이미지** (콘텐츠 슬라이드): 특정 레이아웃 플레이스홀더 내에 포함
- **전체 화면 이미지**: 전체 캔버스 덮기 (0, 0, 26.67", 15.00")
- **프로필 사진** (기여자 슬라이드): 소형 원형 크롭, ~1.5"×1.5", 이름 텍스트 위 가운데 정렬

### 이미지 스타일 가이드라인

- IBM은 **사진** (실제 사람, 실제 환경) 사용 — 스톡 클립아트 금지
- 사진은 자연스럽고 따뜻한 느낌 — 지나치게 연출된 사진 금지
- 어둡거나 대비가 높은 이미지는 흰색 텍스트 뒤에 잘 어울림
- 데이터 중심 슬라이드: 이미지를 작게 유지하고 텍스트 위주로 구성
